# ACTION REQUIRED: Create Your Site Logo

The Organization schema in layout.tsx now references /logo.png.
You need to create this file and place it at:

  public/logo.png

## Logo Specifications (Google Rich Results Requirements)
- Dimensions: 400px wide × 80px tall (5:1 ratio) OR up to 600×60px
- Format: PNG with transparent background preferred
- Content: Your site name "Canada NOC Guide" or a visual logo mark
- File size: Keep under 30KB

## Quick Option (Text-Based Logo)
If you don't have a designer, you can create a simple text logo using:
1. Canva.com (free) — search "horizontal logo" template
2. Google Slides — white text "Canada NOC Guide" on transparent background
3. Paint.NET or GIMP — export as PNG

## Minimum Required
At minimum, a 400×80 PNG with white "CanadaNOCGuide" text on #030712 dark background
matches your existing site design.

The current schema is:
  url: 'https://canadanocguide.com/logo.png'
  width: 400
  height: 80
